# shahorjinal — GitHub Pages sanatçı sitesi

## Yayınlama
1. GitHub'a giriş yapıp **New repository** seç.
2. Depo adını `GITHUBKULLANICIADIN.github.io` yap (`GITHUBKULLANICIADIN` yerine gerçek kullanıcı adın).
3. Depoyu **Public** oluştur.
4. `index.html`, `style.css`, `script.js`, `README.md` dosyalarını ana dizine yükle ve **Commit changes** de.
5. **Settings → Pages → Deploy from a branch** bölümünde `main` ve `/(root)` seçip kaydet.
6. Birkaç dakika sonra `https://GITHUBKULLANICIADIN.github.io/` adresini aç.

## Yayına almadan önce
- Sosyal medya URL'leri `shahorjinal` kullanıcı adına göre tahmin edilmiştir. Gerçek hesap adreslerin farklıysa `index.html` içindeki bağlantıları düzelt; hesabın olmayan platformları kaldır.
- Spotify'daki Jackpot butonu şimdilik Spotify arama sayfasına gider. Doğru şarkının doğrudan Spotify URL'si bulununca bağlantıyı onunla değiştir.
- Biyografini gerçek ve doğrulanabilir bilgilerle kişiselleştir.
- Basın bölümüne yalnızca gerçekten yayımlanmış bağımsız haberleri ekle.

Kendi sitesi, bağımsız medya haberlerinin yerine geçmez ve TikTok mavi tikini garanti etmez.
